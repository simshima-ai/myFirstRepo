チュートリアル

S-CADの基本操作を短時間で把握するための入門ガイドです。

はじめに

S-CADはブラウザで使える2D CADツールです。 インストールやアカウント登録なしで、すぐに作図を始められます。

まずは設定で単位、縮尺、用紙サイズを決め、 その後に基本図形を描き、必要に応じて編集やグループ化を行います。

1. 画面移動と基本操作

マウスホイールでズーム、中ボタンドラッグ または Alt + ドラッグでパンができます。 全体を見ながら細部を調整するには、ズームと移動をすばやく切り替えるのが効率的です。

主なキー操作

キー動作
Space + ドラッグ画面を移動
マウスホイールズームイン / ズームアウト
Ctrl + Z元に戻す
Ctrl + Yやり直す
Delete / Backspace選択中のオブジェクトを削除
Escape現在のツールを解除
Ctrl + Aすべて選択

2. 基本図形を描く

まずは線、円、四角形、アーク、ポリライン、テキストといった 基本ツールから始めるのがおすすめです。 大まかな形を作ったあとに、トリムや移動で整えていくと作業しやすくなります。

主な作図ツール

ツール説明
Line2点間に直線を描く
Circle中心と半径で円を作る
Rect2点の対角指定で四角形を作る
Polyline連続した線分を作る
Arcアークを作成する
Text注釈や寸法文字を配置する

3. 選択と編集

オブジェクトの選択はクリックで行えます。 Shift + クリックで複数選択ができます。 最初から完璧な形を作るより、ある程度ラフに描いてから修正するほうが速い場合が多いです。

トリム、フィレット、移動、回転、パターンコピーを使いながら、 形状を仕上げていきます。

4. 保存と出力

作業を継続したいときは JSON で保存します。 配布や印刷には SVG や PDF、他の CAD とのやり取りには DXF が使えます。
