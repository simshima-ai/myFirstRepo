Tutorial

A quick guide to the basic workflow of S-CAD.

Getting Started

S-CAD is a browser-based 2D CAD tool. You can start drawing immediately without installing software or creating an account. Once the canvas opens, begin by setting your units, scale, and paper size in the settings panel.

The main flow is simple: set up the page, draw the base geometry, edit or group objects as needed, then export the result as JSON, SVG, PDF, or DXF.

1. Navigate the Canvas

Use the mouse wheel to zoom in and out. Pan with the middle mouse button, or drag while holding Alt. Switching smoothly between zoom and pan is the fastest way to work on both overall layout and detail areas.

Main Shortcuts

KeyAction
Space + DragPan the view
Mouse WheelZoom in / out
Ctrl + ZUndo
Ctrl + YRedo
Delete / BackspaceDelete selected objects
EscapeCancel the current tool
Ctrl + ASelect all

2. Draw Basic Geometry

Start with simple tools such as line, circle, rectangle, arc, polyline, and text. These are enough to build most sketches and construction geometry before refinement.

Common Drawing Tools

ToolDescription
LineCreate a straight segment between two points
CircleCreate a circle from center and radius
RectCreate a rectangle from two corner points
PolylineCreate connected line segments
ArcCreate an arc
TextPlace annotation text

3. Select and Edit

Click to select objects. Hold Shift while clicking to add more items. Many edits are faster after rough drawing, so do not worry about perfect geometry at the first pass.

Use trim, fillet, move, rotate, and pattern copy to refine the drawing. You can also reorganize objects into groups for easier management.

4. Save and Export

Save your work in JSON when you want to reopen and continue editing later. Export SVG or PDF for output, and DXF when you need to exchange data with other CAD software.
